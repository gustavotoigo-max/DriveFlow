# DriveFlow Desktop 1.3.0 — Windows

Login com um clique e novo visual. Compatível com o [Android Monitor 0.2.2](https://github.com/gustavotoigo-max/DriveFlow/releases/tag/android-v0.2.2).

## Novidades

- **Entrar com Google**: escolha a conta no navegador, sem selecionar o JSON OAuth.
- Acesso a todas as pastas do Drive por padrão.
- Novo visual: janela sem a barra do Windows, cabeçalho azul-marinho, tema Automático/Claro/Escuro.
- Ícones do Google Drive e do Gmail e textos mais curtos.

## Como atualizar

- **Na 1.2.0**: Configurações → Verificar atualizações → Baixar atualização. Pause os uploads e escolha Instalar e reiniciar.
- **Em versões anteriores**: feche o DriveFlow, baixe `DriveFlow-v1.3.0-portatil.exe` e abra-o com o mesmo usuário do Windows.

A fila e as configurações em `%LOCALAPPDATA%/DriveFlow` são preservadas. Depois de atualizar, desconecte e entre novamente com **Entrar com Google** se quiser usar o cliente embutido.

Windows 10/11 x64. Executável portátil sem assinatura Authenticode.
