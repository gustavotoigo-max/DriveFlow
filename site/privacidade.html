Política de Privacidade

Atualizada em 28 de setembro de 2026. Aplicável ao DriveFlow para Windows, ao DriveFlow Monitor para Android e a esta página.

Responsável e contato

Projeto mantido por Gustavo Toigo para uso pessoal e interno. Para dúvidas ou solicitações sobre dados, entre em contato: gustavo.toigo@gmail.com.

Dados acessados e finalidade

  • Conta Google: e-mail e identificador da conta para indicar qual conta está conectada e vincular corretamente os uploads.
  • Google Drive: nomes, identificadores e metadados das pastas e arquivos acessíveis, para navegar, escolher destinos e verificar envios. O software lê os arquivos locais selecionados e envia seu conteúdo ao Drive autorizado.
  • Permissões: o modo padrão usa drive.file, limitado aos arquivos acessíveis ao aplicativo. A opção de acesso a pastas existentes solicita drive, uma permissão ampla sobre o Drive. O aplicativo a utiliza para suas funções de navegação e upload, não para publicidade ou análise comercial.
  • Dados locais: caminhos, fila, histórico de operações, progresso, configurações e credenciais necessárias para autenticar e retomar envios.
  • Monitoramento opcional: identificador e nome do computador, nome e tamanho do arquivo, bytes enviados, progresso, velocidade, estimativa, destino, fila, estado, versão e horário da atualização.
  • Pareamento Android: identificador de autenticação anônima Firebase, identificação do dispositivo e vínculos com computadores. Códigos QR de uso único autorizam o vínculo.

Onde os dados ficam

Os arquivos selecionados são enviados ao Google Drive da conta autorizada. A fila, configurações e eventos ficam no computador. Tokens Google e dados de sessão protegidos pelo aplicativo usam a proteção DPAPI do Windows, vinculada ao usuário e à máquina. O JSON da conta de serviço Firebase é um arquivo separado, cuja proteção cabe ao responsável pela instalação.

Quando o monitoramento está habilitado, os metadados e vínculos ficam no Cloud Firestore do projeto Firebase configurado. O Android consulta as máquinas pareadas. Nomes de arquivos e destinos podem revelar informações mesmo quando o conteúdo enviado é um ZIP protegido por senha.

Compartilhamento e uso limitado

Os dados são tratados pelos serviços Google Drive e Firebase conforme as funcionalidades habilitadas e suas políticas. Quem administra o projeto Firebase pode ter acesso aos dados de monitoramento. Celulares autorizados podem ler os estados das máquinas pareadas.

O DriveFlow não vende dados, não os utiliza para publicidade e não os usa para treinar modelos de inteligência artificial. Não envia tokens OAuth ou senhas ao documento de telemetria. O uso e a transferência de informações recebidas das APIs Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Retenção e exclusão

O estado de cada computador é sobrescrito; não há histórico de cada atualização de progresso no Firestore. O último estado e os vínculos podem permanecer até sua exclusão. Códigos de pareamento expiram em cinco minutos, mas seus registros podem permanecer no banco até limpeza administrativa.

Desabilitar o monitoramento interrompe novas publicações após a configuração entrar em vigor; não apaga os registros já existentes. Eles podem ser excluídos pelo administrador do projeto Firebase. Dados locais permanecem até sua remoção; desinstalar pode preservá-los. Arquivos já enviados continuam no Drive até serem excluídos pelo usuário.

Suas escolhas

Você pode pausar envios, desabilitar o monitoramento, revogar o acesso de celulares e retirar a autorização Google em Conexões da Conta Google. A retirada da autorização impede novos acessos com aquela credencial, sem excluir arquivos já enviados. Para solicitar orientação sobre acesso ou exclusão de dados no projeto administrado pelo mantenedor, use o contato acima.

Esta página

Esta página estática não inclui formulários, anúncios nem ferramentas próprias de análise ou rastreamento. A hospedagem pelo GitHub Pages pode tratar registros técnicos das visitas, como endereço IP, conforme a Política de Privacidade do GitHub.

Alterações

Esta política pode ser atualizada para refletir mudanças no funcionamento do software. A data no início identifica a versão publicada.
